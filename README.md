## About
Manual implementation of a Multilayer Perceptron (MLP) 
trained on the MNIST handwritten digit dataset using 
NumPy only.

## How to Run
1. Open `src/mlp_mnist_task7.ipynb` in Google Colab
2. Click Runtime → Run All
3. MNIST dataset downloads automatically
4. Three outputs will be generated:
   - Loss curve plot
   - Test accuracy percentage
   - Sample predictions grid

## Network Architecture
- Input: 784 neurons
- Hidden Layer 1: 128 neurons (Sigmoid)
- Hidden Layer 2: 64 neurons (Sigmoid)  
- Output: 10 neurons (Sigmoid)

## Results
- Training Epochs: 20
- Batch Size: 32
- Learning Rate: 0.1
